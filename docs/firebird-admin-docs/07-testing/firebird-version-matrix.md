| Backup | A validar | A validar | A validar | A validar |

| Validation | A validar | A validar | A validar | A validar |

## Estados permitidos

- `Suportado`
- `Parcial`
- `Não suportado`
- `N/A`
- `A validar`

Nunca converter uma suposição de versão em suporte confirmado sem teste/documentação.
